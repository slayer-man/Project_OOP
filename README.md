Ядро для интернет-магазина (электронной торговли), построенное на основе объектно-ориентированного программирования (ООП) на Python. Текущий этап проекта посвящен **переопределению магических методов (дандеров) для оптимизации работы с данными и реализации кастомных итераторов**.

## 🛠 Стек технологий
* **Язык разработки:** Python 3.14+
* **Менеджер зависимостей:** Poetry
* **Тестирование:** Pytest
* **Контроль покрытия тестами:** Pytest-cov
* **Форматирование кода:** Black
* **Проверка стиля кода (линтинг):** Flake8
* **Статический анализатор:** Mypy
* **Модель ветвления:** GitFlow

## 🌿 Новые возможности и архитектурные изменения в версии 16.1

1. **Реализация наследования:**
   * Выделены две новые специализированные категории товаров, унаследованные от базового класса `Product`:
     * **`Smartphone`** (Смартфон): расширен уникальными свойствами — производительность (`efficiency`), модель (`model`), объем встроенной памяти (`memory`) и цвет (`color`).
     * **`LawnGrass`** (Газонная трава): расширен уникальными свойствами — страна-производитель (`country`), срок прорастания (`germination_period`) и цвет (`color`).
   * Базовый класс `Product` остается полностью независимым и может использоваться для описания любых общих товаров.

2. **Строгое сложение по типам классов (`__add__`):**
   * Переопределен магический метод сложения. Теперь операция `a + b` (вычисляющая суммарную стоимость остатков на складе) возможна **строго между продуктами одного и того же класса** (например, `Smartphone + Smartphone`).
   * Использование проверки через функцию `type()` гарантирует, что попытка сложить разнородные объекты (например, смартфон и газонную траву) вызовет исключение `TypeError`.

3. **Защита методов добавления в коллекцию:**
   * Метод `add_product()` в классе `Category` защищен с помощью связки функций `isinstance()` и `issubclass()`.
   * Категория принимает любые объекты класса `Product` и всех его подклассов (`Smartphone`, `LawnGrass`), но гарантированно блокирует добавление посторонних типов данных (чисел, строк и т.д.), выбрасывая ошибку `TypeError`.

## 🚀 Настройка и установка окружения

1. **Клонируйте репозиторий:**
   ```
   git clone https://github.com
   cd Project_OOP
   ```

2. **Установите зависимости через Poetry (без пакетного режима сборки):**
   ```
   python -m poetry install --no-root
   ```

## 💻 Запуск инструментов качества кода

Перед фиксацией изменений в Git обязательно запускайте форматирование и статический анализ.

## 🧪 Тестирование и покрытие (Code Coverage)

Проект полностью покрыт модульными тестами с использованием `pytest`. Логика сложения, строкового вывода, а также поведение итератора протестированы в изолированном режиме. Общий уровень покрытия функционального кода удовлетворяет критерию наставника (>75%).

* **Запуск тестов:**
  ```
  python -m pytest
  ```

* **Запуск тестов с генерацией отчета о покрытии:**
  ```
  python -m pytest --cov=src
  ```

* **Подробный HTML-отчет (откроется в браузере через папку htmlcov):**
  ```
  python -m pytest --cov=src --cov-report=html
  ```

## 🌿 Процесс разработки (GitFlow)
Разработка ведется в строгом соответствии с методологией GitFlow:
1. Основной рабочий код находится в ветке `develop`.
2. Текущее домашнее задание выполнено в изолированной ветке `feature/homework_16_1`.
3. Сдача работы наставнику осуществляется через Pull Request из ветки фичи в ветку `develop`.
