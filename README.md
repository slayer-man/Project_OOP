# Проект ООП — Домашнее задание 17.1 (Обработка исключений и Тестирование)

Реализация механизмов обработки исключений при добавлении товаров в категории, подсчете средней стоимости товаров, а также интеграция пользовательских исключений и замер покрытия кода тестами.

## 🚀 Реализованный функционал

### 1. Обработка создания товара с нулевым количеством
* В конструктор класса `Product` добавлена проверка количества. 
* При попытке инициализировать товар с нулевым количеством выбрасывается базовое исключение `ValueError` с точным сообщением: `"Товар с нулевым количеством не может быть добавлен"`. Выполнение демонстрационной программы при этом прерывается.

### 2. Подсчет средней цены товаров (Защита от ZeroDivisionError)
* В классе `Category` реализован метод `middle_price()`, который рассчитывает среднюю стоимость всех товаров в категории.
* Использование конструкции `try/except` предотвращает падение программы в случае, если категория пуста (обработка деления на ноль `ZeroDivisionError`). В таком случае метод возвращает `0`.

### 3. Пользовательское исключение (Дополнительное задание)
* Создан собственный класс исключения `ZeroQuantityError`, наследующийся от `ValueError`.
* В метод `add_product()` класса `Category` внедрена полная конструкция обработки исключений: `try / except / else / finally`.
* **Логика работы:**
  * `try` — проверка количества добавляемого товара.
  * `except ZeroQuantityError` — перехват ошибки и вывод сообщения в консоль.
  * `else` — успешное добавление товара в список категории с выводом подтверждения.
  * `finally` — гарантированный вывод сообщения `"Обработка добавления товара завершена"` при любом исходе.
