Ядро для интернет-магазина (электронной торговли), построенное на основе объектно-ориентированного программирования (ООП) на Python. Текущий этап проекта посвящен **переопределению магических методов (дандеров) для оптимизации работы с данными и реализации кастомных итераторов**.

## 🛠 Стек технологий
* **Язык разработки:** Python 3.14+
* **Менеджер зависимостей:** Poetry
* **Тестирование:** Pytest
* **Контроль покрытия тестами:** Pytest-cov
* **Форматирование кода:** Black
* **Проверка стиля кода (линтинг):** Flake8
* **Статический анализатор:** Mypy
* **Модель ветвления:** GitFlow

## ✨ Новые возможности и магические методы в версии 15.1
1. **Строковое отображение объектов (`__str__`):**
   * Для класса `Product` переопределен метод `__str__`, который возвращает информацию в понятном пользователю формате: `Название продукта, X руб. Остаток: X шт.`
   * Для класса `Category` метод `__str__` динамически обходит приватный список товаров и суммирует общее количество всех единиц на складе, возвращая строку: `Название категории, количество продуктов: X шт.`
   * Существующий геттер `.products` в категории оптимизирован — теперь он вызывает `str(product)` для каждого объекта.
2. **Арифметическое сложение продуктов (`__add__`):**
   * Для класса `Product` переопределена логика сложения через оператор `+`. При сложении двух товаров возвращается **суммарная стоимость всех их остатков на складе** (вычисляется по формуле: `цена_1 * количество_1 + цена_2 * количество_2`).
   * Реализована строгая проверка типов: сложение возможно только между объектами класса `Product`, в ином случае вызывается ошибка `TypeError`.
3. **Кастомный итератор (`ProductIterator`):**
   * Реализован вспомогательный класс-итератор (`__iter__` и `__next__`), позволяющий перебирать товары конкретной категории внутри стандартного цикла `for`.

## 🚀 Настройка и установка окружения

1. **Клонируйте репозиторий:**
   ```
   git clone https://github.com
   cd Project_OOP
   ```

2. **Установите зависимости через Poetry (без пакетного режима сборки):**
   ```
   python -m poetry install --no-root
   ```

## 💻 Запуск инструментов качества кода

Перед фиксацией изменений в Git обязательно запускайте форматирование и статический анализ.

* **Автоматическое форматирование кода (Black):**

  python -m black src/ tests/

* **Проверка соответствия стандарту PEP 8 (Flake8):**
  ```
  python -m flake8 src/ tests/
  ```

  ```
  python -m mypy src/
  ```

## 🧪 Тестирование и покрытие (Code Coverage)

Проект полностью покрыт модульными тестами с использованием `pytest`. Логика сложения, строкового вывода, а также поведение итератора протестированы в изолированном режиме. Общий уровень покрытия функционального кода удовлетворяет критерию наставника (>75%).

* **Запуск тестов:**
  ```
  python -m pytest
  ```

* **Запуск тестов с генерацией отчета о покрытии:**
  ```
  python -m pytest --cov=src
  ```

* **Подробный HTML-отчет (откроется в браузере через папку htmlcov):**
  ```
  python -m pytest --cov=src --cov-report=html
  ```

## 🌿 Процесс разработки (GitFlow)
Разработка ведется в строгом соответствии с методологией GitFlow:
1. Основной рабочий код находится в ветке `develop`.
2. Текущее домашнее задание выполнено в изолированной ветке `feature/homework_15_1`.
3. Сдача работы наставнику осуществляется через Pull Request из ветки фичи в ветку `develop`.
