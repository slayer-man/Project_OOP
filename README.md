# E-commerce Core Project

Ядро для интернет-магазина (электронной торговли), построенное на основе объектно-ориентированного программирования (ООП) на Python. Текущий этап проекта посвящен **инкапсуляции, защите данных и контролируемому доступу к атрибутам классов**.

## 🛠 Стек технологий
* **Язык разработки:** Python 3.14+
* **Менеджер зависимостей:** Poetry
* **Тестирование:** Pytest
* **Контроль покрытия тестами:** Pytest-cov
* **Форматирование кода:** Black
* **Проверка стиля кода (линтинг):** Flake8
* **Модель ветвления:** GitFlow

## 🔒 Ключевые изменения и инкапсуляция в версии 14.2
1. **Приватный список товаров:** Атрибут списка товаров в классе `Category` сделан приватным (`__products`). Добавление новых объектов возможно строго через контролируемый метод `add_product()`.
2. **Форматированный геттер списка товаров:** Доступ к чтению товаров возвращен через публичное свойство-геттер `@property def products`, которое формирует красивый строковый вывод для интерфейсов по шаблону: `Название продукта, 80 руб. Остаток: 15 шт.`
3. **Фабричный метод создания слияния:** Реализован класс-метод `@classmethod def new_product()`, который умеет не просто создавать объекты из словарей, но и автоматически объединять остатки и выбирать максимальную стоимость при обнаружении дубликатов.
4. **Защищенный сеттер цен:** Поле цены в `Product` инкапсулировано (`__price`). Настроен сеттер `@price.setter` с валидацией от нулевых/отрицательных значений и **интерактивным подтверждением снижения цены** пользователем через консольный ввод `(y/n)`.

```
Project_OOP/
│
├── src/                  # Исходный код ядра приложения
│   ├── __init__.py
│   ├── product.py        # Класс Product (управление товарами)
│   ├── category.py       # Класс Category (управление категориями и статистикой)
│   └── utils.py          # Утилиты (подгрузка данных из JSON)
│
├── tests/                # Модульные тесты
│   ├── __init__.py
│   ├── test_classes.py   # Тестирование инициализации и счетчиков

├── main.py               # Скрипт для проверки работоспособности
├── products.json         # Файл JSON с данными
```

## 🚀 Настройка и установка окружения

1. **Установите зависимости через Poetry (без пакетного режима сборки):**
   ```
   python -m poetry install
   ```

2.**Активируйте виртуальное окружение:**
   ```
   .venv\Scripts\activate
   ```

## 💻 Запуск проекта и инструментов качества

Перед отправкой кода на проверку (Code Review) обязательно запускайте инструменты форматирования и линтинга.

* **Автоматическое форматирование кода (Black):**
  ```
  python -m black src/ tests/ main.py
  ```

* **Проверка соответствия стандарту PEP 8 (Flake8):**
  ```
  python -m flake8 src/ tests/
  ```

* **Запуск демонстрационного скрипта:**
  ```
  python main.py
  ```

## 🧪 Тестирование и покрытие (Code Coverage)

Проект покрыт модульными тестами с использованием `pytest`. Написаны фикстуры для изоляции тестов и автоматического сброса глобальных счетчиков классов.

* **Запуск тестов:**
  ```
  python -m pytest
  ```

* **Запуск тестов с генерацией отчета о покрытии (требуемый уровень >75%):**
  ```
  python -m pytest --cov=src
  ```

* **Подробный отчет со списком строк, не покрытых тестами:**
  ```
  python -m pytest --cov=src --cov-report=term-missing
  ```

## 🌿 Процесс разработки (GitFlow)
Разработка ведется в строгом соответствии с GitFlow:
1. Основной рабочий код находится в ветке `develop`.
2. Каждое домашнее задание выполняется в отдельной ветке формата `feature/homework_XX_X`, созданной от `develop`.
3. Сдача работы наставнику происходит путем создания Pull Request из ветки фичи в ветку `develop`.
